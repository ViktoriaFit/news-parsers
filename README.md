# news-parsers# 📰 News Parser with AI Summary

Парсер новостей с автоматическим резюме от AI и отправкой в Telegram.

## ✨ Возможности

- 📡 **Сбор новостей** — с 5 RSS-источников
- 🔍 **Фильтр по теме** — AI / программирование
- 🤖 **AI-резюме** — через Groq API
- 💾 **Сохранение в JSON** — `news_list.json`
- 📄 **Сохранение резюме** — `news_summary.txt`
- 📤 **Отправка в Telegram** — краткая сводка

## 🛠 Технологии

- **Python 3.12**
- **feedparser** — чтение RSS
- **requests** — HTTP-запросы к Groq и Telegram
- **Groq API** — AI-резюме
- **JSON** — сохранение данных
- **VPN + прокси** — обход блокировок

## 📋 Как работает

1. Читает RSS со **списка источников** (Хабр, Tproger, N+1, Ведомости, Лента).
2. Собирает **все новости** за сегодня.
3. **Фильтрует** — оставляет только новости про AI, Python, разработку.
4. Отправляет **отфильтрованные новости** в AI.
5. AI делает **краткое резюме** (3-5 предложений).
6. Сохраняет **резюме в файл** и **отправляет в Telegram**.
